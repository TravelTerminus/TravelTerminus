# Travel Terminus

Travel technology for travel agencies, online travel agencies and companies that book business travel.

## What we build

- **Flight booking API for online travel agencies**: live GDS, NDC and low cost carrier fares, instant ticketing and self service changes through one integration. [Learn more](https://travelterminus.com/flight-api/online-travel-agencies)
- **B2E corporate travel API**: flight search, booking and ticketing inside ERP, HRMS and expense systems. [Learn more](https://travelterminus.com/flight-api/corporate-travel)
- **B2B flight booking portal** for travel agents and sub agents
- **WhatsApp flight booking engine** for travel agencies
